TaxaScope KRIBB-KCTC Guide

TaxaScope KRIBB-KCTC 用户指南

欢迎使用 TaxaScope KRIBB-KCTC！本手册将引导您完成从环境安装到执行生物信息学分析的全过程。

1. 软件概述

TaxaScope KRIBB-KCTC 是一个基于 Windows 的图形化工具箱，旨在简化复杂的生物信息学分析流程。

  • 离线运行：支持导入预打包的镜像，无需持续联网。
  • 原生体验：提供简单的点击式界面，无需记忆复杂的 Linux 命令。

2. 环境安装 (第一次使用必看)

根据您的操作系统版本，安装步骤略有不同：

Windows 11 用户

  1. 打开软件，直接点击右上角的 "⚙️ Env Setup" 按钮。
  2. 关键步骤：安装完成后，请务必 重启电脑。

Windows 10 用户 (版本 1903+)

由于 Windows 10 的 WSL2 内核需要手动更新，请按照以下步骤操作：

  1. 点击 "🔧 Win10 WSL2" 按钮
  2. 关键步骤：完成后请务必 重启电脑。
⚠️ IMPORTANT

重启是必须的！ 只有重启后，Windows 才能激活虚拟化平台。

3. 分析准备 (镜像导入)

软件中的分析工具是以容器镜像形式运行的，您可以根据自己的网络情况选择加载方式：

方式 A：离线手动导入 (推荐网络受限用户)

  1. 如果您已经拥有预打包的 .tar 镜像文件（通常存放在 TaxaScope_Images/ 文件夹下）。
  2. 在软件界面点击 "📥 Import Images" 按钮并选择该文件。
  3. 程序会自动将其导入 Podman 引擎。

方式 B：在线自动下载 (推荐拥有国际互联网连接的用户)

  1. 如果您可以顺畅访问国外网络（Docker Hub），则无需手动导入。
  2. 直接点击对应工具页面的运行按钮，系统会自动从云端下载所需镜像。
  3. 注意：首次运行时的下载过程可能较长，具体取决于您的带宽。

4. 日常使用流程

第一步：开启后台 (自动/手动)

  • 自动：现在软件启动时会自动检查并尝试运行 podman machine start。
  • 手动：如果自动启动失败，可以点击 "💻 VM Config" 重新配置并启动。
  • 低性能模式 (Low Perf Mode)：位于界面右上角。开启后会限制容器使用的 CPU 核心数，防止旧电脑或配置较低的系统在分析时出现完全卡死的情况。

第二步：选择工作目录

  1. 点击 "📂 Select Work Directory" 选择您的数据所在的文件夹。
  2. 左侧的 "File Browser" 会立即加载该目录下的文件。

第三步：运行分析 (单工具或批量)

  • 单工具运行：在顶部的标签页中选择工具，配置参数后点击底部按钮。
    • dbCAN2 选项：建议至少勾选两种方法（HMMER, DIAMOND, dbCAN-sub）以获得更可靠的预测结果。
    • CHECKM2 选项：小于等于16g内存，建议打开低性能模式作者信息附近的开关。
    • antiSMASH 选项：
      • Strictness: 默认为 relaxed。
      • High Memory 特性: 部分功能（如 ClusterBlast）建议在内存大于等于 32GB 的机器上开启。
  • 批量运行 (Batch Analysis)：
    1. 切换到 "Batch Analysis" 标签页。
    2. 勾选您想要依次运行的所有工具（如 Prokka + dbCAN + CheckM2）。
    3. 勾选 "📊 Generate Full Report (HTML)" 以在完成后生成汇总报告。
    4. 点击底部的 "▶ Run Selected Tools"。

第四步：监控与查看报告

  • Monitor 标签页：查看当前运行时间、工具队列和运行状态。
  • 交互式报告 (Batch Report)：
    1. 批量运行结束后，软件会自动在默认浏览器中打开一个 .html 格式的汇总报告。
    2. 报告集成了所有工具的图表、结果预览和质量评价。
    3. 该报告支持点击放大图片，并可在不同工具的 Tab 之间切换。
  • Preview 标签页：分析完成后，单个结果文件也可以在这里预览。

5. 退出软件

为了保护您的系统资源，退出时会有提示：

  • 选择“是”：立即执行 wsl --shutdown。这会彻底释放 WSL 占用的内存（有时多达数 GB），但下次打开软件会稍慢, 需要等待 ✅Env Ready 再开始操作。
  • 选择“否”：直接退出 UI。WSL 后台保持运行，方便您下次秒速启动分析。

6. 常见问题 (FAQ)

Q: 运行分析时提示 "Cannot connect to Podman"？

A: 这通常是因为 WSL 后台没启动。尝试点击 "VM Config" 或重启软件。

Q: 磁盘空间不足？

A: 生物信息学镜像占用很大。您可以在不再需要某个工具时，点击工具页下方的 "🗑️ Uninstall [工具名] (Free Space)"。

Q: 想要自定义内存和 CPU 分配？

A: 点击 "VM Config"。默认会自动分配系统 70% 的内存和 75% 的 CPU 核心，以保证分析效率。

Q: 软件运行中卡死了怎么办？

A: 点击最底部的红色按钮 "⏹ Stop Current Task"。这会尝试强制终止所有正在运行的功能。

TaxaScope KRIBB-KCTC User Guide

Welcome to TaxaScope KRIBB-KCTC! This manual will guide you through the entire process from environment setup to executing bioinformatics analyses.

1. Software Overview

TaxaScope KRIBB-KCTC is a Windows-based graphical toolbox designed to simplify complex bioinformatics workflows.

  • Offline Operation: Supports importing pre-packaged images without requiring constant internet access.
  • Native Experience: Offers a simple click-based interface, eliminating the need to memorize complex Linux commands.

2. Environment Setup (Required for First-Time Users)

Installation steps vary slightly based on your operating system version:

Windows 11 Users

  1. Open the software and click the "⚙️ Env Setup" button in the top-right corner.
  2. Critical Step: After installation, reboot your computer.

Windows 10 Users (Version 1903+)

Due to the manual update requirement for Windows 10's WSL2 kernel, follow these steps:

  1. Click the "🔧 Win10 WSL2" button.
  2. Critical Step: Reboot your computer after completion.
⚠️ IMPORTANT

Rebooting is mandatory! Only after a reboot will Windows activate the virtualization platform.

3. Analysis Preparation (Image Import)

Analysis tools in the software run as container images. Choose your preferred loading method based on your internet access:

Option A: Offline Manual Import (Recommended for Limited-Network Users)

  1. If you already have a pre-packaged .tar image file (typically stored in the TaxaScope_Images/ folder).
  2. Click the "📥 Import Images" button in the software interface and select the file.
  3. The program will automatically import it into the Podman engine.

Option B: Online Auto-Download (Recommended for Users with Overseas Network Access)

  1. If you can reliably access international networks (e.g., Docker Hub), manual import is unnecessary.
  2. Click the run button on the respective tool page, and the system will automatically download the required image from the cloud.
  3. Note: The initial download may take longer depending on your bandwidth.

4. Daily Workflow

Step 1: Start Background Services (Auto/Manual)

  • Auto: The software now automatically checks and attempts to run podman machine start upon launch.
  • Manual: If auto-start fails, click "💻 VM Config" to reconfigure and start manually.
  • Low-Perf Mode: Located in the top-right corner. Enabling this limits CPU cores used by containers to prevent system freezes on older or low-configuration machines.

Step 2: Select Working Directory

  1. Click "📂 Select Work Directory" to choose the folder containing your data.
  2. The "File Browser" on the left will immediately load files from this directory.

Step 3: Run Analysis (Single Tool or Batch)

  • Single-Tool Execution: Select the tool from the top tabs, configure parameters, and click the bottom button.
    • dbCAN2 Option: It is recommended to select at least two methods (HMMER, DIAMOND, dbCAN-sub) for more reliable prediction results.
    • CheckM2 Option: ≤16GB RAM, enable Low-Perf Mode via the switch near the author info.
    • antiSMASH Option:
      • Strictness: Default is relaxed.
      • High-Memory Features: Certain functions (e.g., ClusterBlast) should be enabled only on machines with ≥32GB RAM.
  • Batch Execution:
    1. Switch to the "Batch Analysis" tab.
    2. Check all tools you wish to run sequentially (e.g., Prokka + dbCAN + CheckM2).
    3. Check "📊 Generate Full Report (HTML)" to create a summary report upon completion.
    4. Click "▶ Run Selected Tools" at the bottom.

Step 4: Monitor and View Reports

  • Monitor Tab: View current runtime, tool queue, and execution status.
  • Interactive Report (Batch Report):
    1. After batch execution, the software automatically opens a consolidated .html report in your default browser.
    2. The report integrates charts, result previews, and quality assessments.
    3. Supports image zooming and tab-switching between tools.
  • Preview Tab: View individual result files after analysis completion.

5. Exiting the Software

To protect your system resources, a prompt will appear upon exit:

  • Select "Yes": Immediately executes wsl --shutdown. This fully releases memory, but next opening will be slower. Wait for ✅ Env Ready.
  • Select "No": Exits the UI directly. WSL remains running in the background.

6. Frequently Asked Questions (FAQ)

Q: Error "Cannot connect to Podman"?

A: Usually because WSL backend hasn't started. Try clicking "VM Config" or restarting.

Q: Running out of disk space?

A: Bioinformatics images are large. Click "🗑️ Uninstall [Tool Name]" when no longer needed.

Q: Customize memory and CPU?

A: Click "VM Config". By default, it allocates 70% RAM and 75% CPU.

Q: What if the software freezes?

A: Click "⏹ Stop Current Task" at the bottom to kill all running functions.

TaxaScope KRIBB-KCTC 사용자 가이드

TaxaScope KRIBB-KCTC에 오신 것을 환영합니다! 이 설명서는 환경 설정부터 생물정보학(Bioinformatics) 분석 실행까지의 전 과정을 안내합니다.

1. 소프트웨어 개요

TaxaScope KRIBB-KCTC은 복잡한 생물정보학 워크플로우를 단순화하기 위해 설계된 Windows 기반의 그래픽 툴박스입니다.

  • 오프라인 작동: 지속적인 인터넷 연결 없이도 사전 패키징된 이미지를 가져와 사용할 수 있습니다.
  • 네이티브 경험: 복잡한 리눅스 명령어를 외울 필요 없이 간단한 클릭 기반의 인터페이스를 제공합니다.

2. 환경 설정 (최초 사용자 필수)

설치 단계는 운영 체제 버전에 따라 약간 다릅니다.

Windows 11 사용자

  1. 소프트웨어를 실행하고 우측 상단의 "⚙️ Env Setup" 버튼을 클릭합니다.
  2. 중요 단계: 설치 완료 후, 반드시 컴퓨터를 다시 시작하십시오.

Windows 10 사용자 (버전 1903 이상)

Windows 10의 WSL2 커널 수동 업데이트가 필요하므로 다음 단계를 따르세요.

  1. "🔧 Win10 WSL2" 버튼을 클릭합니다.
  2. 중요 단계: 완료 후 반드시 컴퓨터를 다시 시작하십시오.
⚠️ IMPORTANT

재부팅은 필수입니다! 재부팅 후에만 Windows에서 가상화 플랫폼이 활성화됩니다.

3. 분석 준비 (이미지 임포트)

소프트웨어의 분석 도구들은 컨테이너 이미지로 실행됩니다. 네트워크 환경에 따라 적절한 로드 방법을 선택하세요.

옵션 A: 오프라인 수동 임포트 (네트워크 제한 환경 권장)

  1. 사전 패키징된 .tar 이미지 파일이 있는 경우(보통 TaxaScope_Images/ 폴더에 저장됨).
  2. 인터페이스에서 "📥 Import Images" 버튼을 클릭하고 해당 파일을 선택합니다.
  3. 프로그램이 자동으로 Podman 엔진에 이미지를 가져옵니다.

옵션 B: 온라인 자동 다운로드 (해외 네트워크 접속 원활 시 권장)

  1. Docker Hub 등 국제 네트워크에 안정적으로 접속할 수 있는 경우, 수동 임포트가 필요하지 않습니다.
  2. 각 도구 페이지에서 실행 버튼을 클릭하면 시스템이 클라우드에서 필요한 이미지를 자동으로 다운로드합니다.
  3. 참고: 대역폭에 따라 초기 다운로드 시간이 다소 소요될 수 있습니다.

4. 일일 워크플로우

1단계: 백그라운드 서비스 시작 (자동/수동)

  • 자동: 이제 소프트웨어 실행 시 자동으로 podman machine start를 확인하고 실행을 시도합니다.
  • 수동: 자동 시작에 실패하면 "💻 VM Config"를 클릭하여 수동으로 재설정하고 시작하십시오.
  • 저사양 모드(Low-Perf Mode): 우측 상단에 위치합니다. 이 모드를 활성화하면 컨테이너가 사용하는 CPU 코어 수를 제한하여 저사양 PC에서의 시스템 프리징을 방지합니다.

2단계: 작업 디렉토리 선택

  1. "📂 Select Work Directory"를 클릭하여 데이터가 포함된 폴더를 선택합니다.
  2. 왼쪽의 "File Browser"에 해당 디렉토리의 파일이 즉시 로드됩니다.

3단계: 분석 실행 (단일 도구 또는 일괄 처리)

  • 단일 도구 실행: 상단 탭에서 도구를 선택하고 파라미터를 설정한 후 하단 버튼을 클릭합니다.
    • dbCAN2 옵션: 더 신뢰도 높은 예측 결과를 위해 최소 두 가지 방법(HMMER, DIAMOND, dbCAN-sub)을 선택하는 것이 좋습니다.
    • CheckM2 옵션: RAM이 16GB 이하인 경우, 저사양 모드를 활성화하십시오.
    • antiSMASH 옵션:
      • 엄격도(Strictness): 기본값은 relaxed입니다.
      • 고메모리 기능: ClusterBlast 등 일부 기능은 RAM 32GB 이상의 기기에서만 권장합니다.
  • 일괄 실행 (Batch Execution):
    1. "Batch Analysis" 탭으로 전환합니다.
    2. 순차적으로 실행할 도구들을 체크합니다 (예: Prokka + dbCAN + CheckM2).
    3. 완료 후 요약 보고서를 생성하려면 "📊 Generate Full Report (HTML)"를 체크합니다.
    4. 하단의 "▶ Run Selected Tools"를 클릭합니다.

4단계: 모니터링 및 보고서 확인

  • Monitor 탭: 현재 실행 시간, 도구 대기열 및 실행 상태를 확인합니다.
  • 대화형 보고서 (Batch Report):
    1. 일괄 실행이 완료되면 통합된 .html 보고서가 자동으로 열립니다.
    2. 보고서에는 차트, 결과 미리보기, 품질 평가가 포함됩니다.
    3. 이미지 확대 및 도구 간 탭 전환을 지원합니다.
  • Preview 탭: 분석 완료 후 개별 결과 파일을 확인합니다.

5. 소프트웨어 종료

시스템 리소스를 보호하기 위해 종료 시 다음과 같은 프롬프트가 표시됩니다.

  • "Yes" 선택: 즉시 wsl --shutdown을 실행합니다. 메모리를 완전히 해제하지만, 다음 실행 시 속도가 약간 느려질 수 있습니다. ✅ Env Ready 상태를 기다려야 합니다.
  • "No" 선택: UI만 종료합니다. WSL은 백그라운드에서 계속 실행됩니다.

6. 자주 묻는 질문 (FAQ)

Q: "Cannot connect to Podman" 오류 발생?

A: 보통 WSL 프로세스가 시작되지 않았기 때문입니다. "VM Config"를 클릭하거나 재시작해 보세요.

Q: 디스크 공간 부족?

A: 이미지가 용량을 많이 차지합니다. 필요 없는 도구는 "🗑️ Uninstall" 하세요.

Q: 메모리와 CPU 사용자 지정?

A: "VM Config"에서 가능합니다. 기본 70% RAM, 75% CPU 할당.

Q: 소프트웨어가 멈추면?

A: "⏹ Stop Current Task"를 클릭하여 모든 기능을 종료하세요.
