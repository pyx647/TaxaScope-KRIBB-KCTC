# Report Showcase

This folder contains example output reports generated by **TaxaScope KRIBB-KCTC**
on a benchmark dataset of *Pseudomonas* and related genomes. The reports
illustrate what a complete TaxaScope run produces for downstream interpretation
and manuscript writing.

## What TaxaScope Produces Per Run

After every batch run, TaxaScope writes three companion files into the working
directory:

| File | Purpose |
| :--- | :--- |
| `TaxaScope_Report.html` | Interactive HTML report — open in any browser. Includes tabbed sections per tool, embedded plots, sortable tables, and image previews. |
| `TaxaScope_Run_Report.md` | Markdown report — concise summary tables suitable for direct paste into manuscripts, lab notebooks, or GitHub issues. Contains the `Methods` block ready for citation. |
| `TaxaScope_Run_Manifest.json` | Machine-readable provenance — full command lines, tool versions, database versions, container image digests, parameters, input/output file lists, durations. Use this for reproducibility audits. |

## Sections Covered

A complete report contains the following analysis sections:

- **Genome Stats** — assembly metrics (N50, GC%, contig count, total length)
- **Prokka** — gene/CDS/rRNA/tRNA annotation, per-genome circular plots
- **dbCAN** — CAZyme family annotation (HMMER + DIAMOND + dbCAN-sub)
- **CheckM2** — genome completeness and contamination assessment
- **BUSCO** — single-copy orthologue completeness against `bacteria_odb12`
- **antiSMASH** — biosynthetic gene cluster detection with cluster heatmap
- **PhyloPhlAn** — phylogenetic tree (IQ-TREE LG+G4, 100 standard non-parametric bootstrap, SH-aLRT 1000)
- **AAI / ANI** — pairwise average amino-acid and nucleotide identity heatmaps for species delineation

## How to View

- **HTML report**: double-click to open in browser. All assets (images, charts) are embedded as base64 — the file is fully self-contained and shareable.
- **Markdown report**: render in any Markdown viewer (VS Code, GitHub, Typora). The Methods section can be copied directly into a manuscript.
- **JSON manifest**: open with any text editor or pipe into `jq` for analysis.

## Reproducibility

Every report includes:
- exact tool version (e.g. Prokka 1.14.6, BUSCO 5.8.2, IQ-TREE LG+G4)
- exact database version with date or Zenodo record
- container image tag pinned per release (e.g. `pyx07/dbcan:v5-nodb-release`)
- full parameter set and runtime duration

This guarantees that the same input data + same TaxaScope release will produce
identical numerical results.
