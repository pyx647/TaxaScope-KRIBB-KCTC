1. Overview

TaxaScope is a Windows desktop application for microbial genome analysis. It combines WSL2, Podman/Docker, containerized tools, working-directory management, file preview, and provenance reporting into one graphical workflow.

The practical workflow is:

Open TaxaScope.exe
-> Env Setup
-> Select Work Directory
-> Download DBs
-> Get Data or add local files
-> configure modules
-> Batch
-> DEPLOY COMPLETE WORKFLOW
-> inspect Runtime, Console, Preview, and reports

2. First-Time Setup

  1. Run TaxaScope.exe.
  2. Click Env Setup on first use. This initializes WSL2 and the container engine.
  3. On Windows 10, complete the WSL2 helper steps and reboot if prompted.
  4. Open TaxaScope again and confirm that the button shows Env Ready.
  5. Use VM Config only when the Podman VM needs memory/CPU adjustment or repair.
  6. Enable Low Perf Mode on memory-limited systems, especially for CheckM2 and antiSMASH.

4. Input Data

NCBI accessions

Open Get Data, enter one GCA/GCF accession per line, select file types, and click Start Download. TaxaScope can retrieve genome FASTA, protein FAA, GBFF, GFF3, and assembly JSON reports. Metadata is preserved as metadata.json when available.

Local files

Local files can be placed directly in the working directory. Protein-based modules require .faa files, which can be downloaded from NCBI or generated by Prokka.

5. GUI Workflow

Figure 2. Text-based legend for the TaxaScope GUI workflow.

  1. Click Env Setup for first-time environment installation. Wait for Env Ready.
  2. Click Select Work Directory and choose the project folder.
  3. Click Download DBs to install reference databases and record database provenance.
  4. Use Get Data to download genomes, or place local files in the working directory.
  5. Open module tabs to adjust parameters, such as dbCAN methods or antiSMASH strictness.
  6. Open Batch. Use Data Acquisition (Optional) for accession-driven runs and Analysis Sequence Setup for module selection.
  7. Keep Auto-generate Interactive HTML Research Report enabled when a final report is needed.
  8. Click DEPLOY COMPLETE WORKFLOW.
  9. Use Runtime, Console, File Browser, and Preview to monitor and inspect results.

7. Reports and Reproducibility

TaxaScope writes three reviewer-friendly reproducibility outputs:

  • TaxaScope_Run_Manifest.json: machine-readable manifest with software, database, parameter, runtime, input, and output metadata.
  • TaxaScope_Run_Report.md: readable Markdown summary for supplementary methods and reviewer responses.
  • TaxaScope_Report.html: interactive report aggregating tables, plots, runtime summaries, and reproducibility information.

8. Troubleshooting

  • If Env Ready does not appear, start Podman or Docker Desktop and reopen TaxaScope. Use VM Config if the Podman VM needs repair.
  • If a database is missing, select the same working directory and click Download DBs again.
  • If no files are detected, check file extensions. dbCAN and PhyloPhlAn require .faa.
  • If NCBI download fails, retry with smaller accession batches, for example 5 to 8 genomes.
  • If a module fails because of memory, enable Low Perf Mode or increase Podman VM memory through VM Config.

1. 软件概述

TaxaScope 是一个面向 Windows 的微生物基因组分析桌面 GUI。它把 WSL2、Podman/Docker、容器化分析工具、工作目录管理、结果预览和复现性报告整合到一个界面中。

推荐用户按下面顺序操作：

打开 TaxaScope.exe
-> 点击 Env Setup 安装/初始化环境
-> 点击 Select Work Directory 选择项目目录
-> 点击 Download DBs 下载数据库
-> 用 Get Data 下载 NCBI 数据，或放入本地文件
-> 配置各分析模块参数
-> 进入 Batch
-> 点击 DEPLOY COMPLETE WORKFLOW
-> 查看 Runtime、Console、Preview 和报告

2. 首次环境设置

  1. 运行 TaxaScope.exe。
  2. 首次使用时点击 Env Setup。该步骤会初始化 WSL2 和容器运行环境。
  3. Windows 10 用户如果按提示安装 WSL2 组件，完成后需要重启电脑。
  4. 重新打开 TaxaScope，确认按钮显示为 Env Ready。
  5. VM Config 不是常规第一步，只在 Podman VM 需要调整内存、CPU 或修复时使用。
  6. 内存较低的机器建议开启 Low Perf Mode，尤其是运行 CheckM2 和 antiSMASH 时。

4. 输入数据

NCBI accession 下载

进入 Get Data 标签页，每行输入一个 GCA/GCF accession，选择需要的文件类型，然后点击 Start Download。TaxaScope 可下载基因组 FASTA、蛋白 FAA、GBFF、GFF3 和 assembly JSON report。可用的 NCBI 元数据会保存在 metadata.json。

本地文件

也可以直接把本地文件放进工作目录。需要注意，dbCAN 和 PhyloPhlAn 使用蛋白序列 .faa；这些文件可以从 NCBI 下载，也可以先运行 Prokka 生成。

5. GUI 工作流

图 2. TaxaScope GUI 工作流文字说明。

  1. 点击 Env Setup 完成首次环境安装，等待状态变为 Env Ready。
  2. 点击 Select Work Directory，选择本次分析的项目文件夹。
  3. 点击 Download DBs，下载参考数据库并记录数据库来源信息。
  4. 通过 Get Data 下载基因组，或把本地文件直接放入工作目录。
  5. 进入各模块标签页调整参数，例如 dbCAN 方法、antiSMASH strictness、Low Perf Mode 等。
  6. 进入 Batch。左侧 Data Acquisition (Optional) 可填写 accession；右侧 Analysis Sequence Setup 勾选要顺序运行的模块。
  7. 如果需要汇总报告，保持 Auto-generate Interactive HTML Research Report 开启。
  8. 点击 DEPLOY COMPLETE WORKFLOW 启动完整流程。
  9. 通过 Runtime、Console、左侧文件浏览器和 Preview 查看进度、日志和结果。

7. 复现性报告

TaxaScope 会输出三类适合审稿和复现记录的文件：

  • TaxaScope_Run_Manifest.json：机器可读，记录软件、数据库、参数、运行时间、输入和输出。
  • TaxaScope_Run_Report.md：人类可读，可用于补充材料、方法描述和回复审稿人。
  • TaxaScope_Report.html：交互式汇总报告，整合表格、图片、运行时间和复现性信息。

8. 故障排查

  • 如果没有显示 Env Ready，先启动 Podman 或 Docker Desktop，再重新打开 TaxaScope；Podman VM 异常时使用 VM Config。
  • 如果提示数据库缺失，确认当前工作目录下有 TaxaScope_Databases，然后再次点击 Download DBs。
  • 如果检测不到文件，检查扩展名；dbCAN 和 PhyloPhlAn 需要 .faa。
  • 如果 NCBI 下载失败，建议缩小 accession 批次，例如每次 5 到 8 个基因组。
  • 如果模块因内存失败，开启 Low Perf Mode，或通过 VM Config 增加 Podman VM 内存。

TaxaScope는 Windows용 미생물 유전체 분석 GUI입니다. WSL2, Podman/Docker, 컨테이너 기반 분석 도구, 작업 폴더 관리, 결과 미리보기, 재현성 보고를 하나의 데스크톱 워크플로로 통합합니다.

2. 최초 환경 설정

  1. TaxaScope.exe를 실행합니다.
  2. 처음 사용할 때 Env Setup을 클릭하여 WSL2와 컨테이너 런타임을 초기화합니다.
  3. Windows 10에서는 WSL2 설정 후 재부팅이 필요할 수 있습니다.
  4. 다시 실행한 뒤 Env Ready 상태를 확인합니다.
  5. VM Config는 Podman VM 메모리/CPU 조정 또는 복구가 필요할 때 사용합니다.
  6. 메모리가 제한된 시스템에서는 Low Perf Mode를 사용합니다.

3. 작업 폴더와 데이터베이스

Select Work Directory를 클릭하여 프로젝트 폴더를 선택합니다. 입력 파일, NCBI 다운로드, 데이터베이스, 중간 파일, 모듈 출력, 보고서가 이 폴더에 저장됩니다.

그 다음 Download DBs를 클릭하여 TaxaScope_Databases를 만들고 데이터베이스 출처와 버전 정보를 기록합니다.

4. 입력 데이터

Get Data 탭에서 GCA/GCF accession을 한 줄에 하나씩 입력하고 Start Download를 클릭합니다. 또는 FASTA/FAA/GBK/GBFF 파일을 작업 폴더에 직접 넣습니다. dbCAN과 PhyloPhlAn은 .faa 단백질 파일을 사용합니다.

  • TaxaScope_Run_Manifest.json: 소프트웨어, 데이터베이스, 매개변수, 입력, 출력 정보를 담은 기계 판독형 기록.

8. 문제 해결

  • Env Ready가 보이지 않으면 Podman 또는 Docker Desktop을 시작하고 TaxaScope를 다시 실행합니다.
  • 데이터베이스가 없다고 나오면 같은 작업 폴더에서 Download DBs를 다시 실행합니다.
  • 파일이 감지되지 않으면 확장자를 확인합니다. dbCAN과 PhyloPhlAn은 .faa가 필요합니다.
  • NCBI 다운로드 실패 시 accession 수를 줄여 다시 시도합니다.
  • 메모리 부족 시 Low Perf Mode를 켜거나 VM Config에서 VM 메모리를 늘립니다.
