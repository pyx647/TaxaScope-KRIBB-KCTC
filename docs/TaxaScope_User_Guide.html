1. Overview

TaxaScope is an integrated GUI toolkit for microbial genome analysis on Windows. It provides a guided environment for configuring, executing, inspecting, and documenting genome-based taxonomic workflows.

  • Genome assembly statistics and annotation
  • Genome quality and completeness assessment
  • CAZyme and biosynthetic gene cluster analysis
  • ANI/AAI comparison and whole-genome phylogeny
  • HTML, Markdown, and JSON reproducibility reporting

2. Graphical User Interface and Workflow Configuration

Figure 2. Graphical user interface (GUI) of TaxaScope and workflow configuration. Numbered elements indicate: (1) environment setup, (2) working directory selection, (3) database download, (4) parameter configuration, (5) optional NCBI data acquisition or local input, (6) batch workflow selection, and (7) workflow execution.

The left panel displays the file browser. The central panel presents workflow configuration and module selection. The right panel contains Runtime, Console, and Preview tabs for progress monitoring, logs, troubleshooting, and result visualization.

3. System Requirements

  • Windows 10 or Windows 11
  • WSL2
  • Podman or Docker Desktop configured for Linux containers
  • At least 16 GB RAM for small bacterial genome batches
  • 32 GB RAM or higher for CheckM2, antiSMASH, and larger batch workflows
TaxaScope primarily uses Podman on Windows, while the main analysis modules include Docker fallback support when Docker Desktop is installed and running.

5. Database Setup

Reference databases are stored under the selected working directory:

<working directory>/TaxaScope_Databases

The database folder includes database_sources.json, which records database names, versions, download sources, and notes for reproducibility reporting.

6. Complete Analysis Case

  1. Prepare genome FASTA files or download genomes through the Get Data panel.
  2. Select the project folder as the working directory.
  3. Download required databases using Download DBs.
  4. Configure tool-specific parameters.
  5. Select modules in batch mode and run the workflow.
  6. Inspect outputs using the file browser and Preview panel.

A typical workflow can include Genome Stats, Prokka, CheckM, BUSCO, dbCAN, antiSMASH, PhyloPhlAn, and AAI/ANI.

7. Reproducibility Reports

  • TaxaScope_Run_Manifest.json: machine-readable run manifest.
  • TaxaScope_Run_Report.md: human-readable Markdown run report.
  • TaxaScope_Report.html: interactive HTML report with results and provenance.

8. Troubleshooting

If the container runtime is unavailable, install or start Podman or Docker Desktop. If databases are missing, run Download DBs and confirm that TaxaScope_Databases/database_sources.json exists. If a module fails because of memory, enable Low Perf Mode or increase container runtime memory allocation.

1. 软件概述

TaxaScope 是一个面向 Windows 的微生物基因组分析 GUI 工具。它将容器化执行、工作目录管理、数据库追踪、批量流程配置、结果预览和结构化运行报告整合到一个桌面界面中。

  • 基因组统计和注释
  • 基因组质量和完整性评估
  • CAZyme 和次级代谢基因簇分析
  • ANI/AAI 比较和全基因组系统发育分析
  • HTML、Markdown 和 JSON 复现性报告

2. 图形界面和工作流配置

图 2. TaxaScope 图形用户界面和工作流配置。编号表示主要操作步骤：(1) 环境初始化，(2) 工作目录选择，(3) 数据库下载，(4) 参数配置，(5) 可选的 NCBI 数据获取或本地文件输入，(6) 批量工作流选择，(7) 一键执行工作流。

左侧面板是文件浏览器，显示工作目录中的输入、中间文件和输出。中间面板用于配置流程和选择分析模块。右侧面板包含 Runtime、Console 和 Preview 三个标签，用于查看进度、日志、故障排查和结果预览。

3. 系统要求

  • Windows 10 或 Windows 11
  • WSL2
  • Podman 或配置为 Linux containers 的 Docker Desktop
  • 小规模细菌基因组分析建议至少 16 GB 内存
  • CheckM2、antiSMASH 和较大批量流程建议 32 GB 或更高内存
TaxaScope 在 Windows 上默认优先使用 Podman；主要分析模块在 Docker Desktop 已安装并运行时也支持 Docker fallback。

参考数据库存放在所选工作目录下：

6. 完整分析案例

  1. 准备基因组 FASTA 文件，或通过 Get Data 输入 NCBI accession 下载基因组。
  2. 选择项目文件夹作为工作目录。
  3. 点击 Download DBs 下载所需数据库。
  4. 根据需要配置各模块参数。
  5. 在 Batch 模式选择模块并执行工作流。
  6. 通过文件浏览器和 Preview 面板查看结果。

常见流程包括 Genome Stats、Prokka、CheckM、BUSCO、dbCAN、antiSMASH、PhyloPhlAn 和 AAI/ANI。

7. 复现性报告

  • TaxaScope_Run_Manifest.json：机器可读的运行记录。
  • TaxaScope_Run_Report.md：人工可读的 Markdown 运行报告。
  • TaxaScope_Report.html：包含结果和 provenance 的交互式 HTML 报告。

8. 故障排查

如果容器运行时不可用，请启动或安装 Podman/Docker Desktop。如果数据库缺失，请运行 Download DBs 并确认 TaxaScope_Databases/database_sources.json 存在。如果模块因内存不足失败，请启用 Low Perf Mode 或提高容器运行时内存。

1. 개요

TaxaScope는 Windows 환경에서 미생물 유전체 분석을 수행하기 위한 GUI 도구입니다. 컨테이너 실행, 작업 폴더 관리, 데이터베이스 추적, 배치 워크플로 설정, 결과 미리보기, 구조화된 실행 보고서를 하나의 인터페이스로 제공합니다.

  • 유전체 통계 및 주석
  • 유전체 품질 및 완전성 평가
  • CAZyme 및 생합성 유전자 클러스터 분석
  • ANI/AAI 비교 및 전장 유전체 계통분석
  • HTML, Markdown, JSON 재현성 보고서

2. GUI 및 워크플로 설정

그림 2. TaxaScope GUI 및 워크플로 설정. 번호는 (1) 환경 설정, (2) 작업 폴더 선택, (3) 데이터베이스 다운로드, (4) 매개변수 설정, (5) 선택적 NCBI 데이터 수집 또는 로컬 입력, (6) 배치 워크플로 선택, (7) 워크플로 실행을 나타냅니다.

왼쪽 패널은 파일 브라우저입니다. 가운데 패널은 워크플로 및 모듈 설정을 표시합니다. 오른쪽 패널은 Runtime, Console, Preview 탭을 통해 진행 상황, 로그, 문제 해결, 결과 미리보기를 제공합니다.

3. 시스템 요구사항

  • Windows 10 또는 Windows 11
  • WSL2
  • Linux containers로 설정된 Podman 또는 Docker Desktop
  • 소규모 세균 유전체 배치에는 최소 16 GB RAM 권장
  • CheckM2, antiSMASH 및 대규모 배치에는 32 GB 이상 권장
TaxaScope는 Windows에서 Podman을 우선 사용하지만, 주요 분석 모듈은 Docker Desktop이 실행 중인 경우 Docker fallback을 지원합니다.

5. 데이터베이스 설정

참조 데이터베이스는 선택한 작업 폴더 아래에 저장됩니다.

<working directory>/TaxaScope_Databases

database_sources.json 파일은 데이터베이스 이름, 버전, 다운로드 출처, 메모를 기록하며 재현성 보고서에 사용됩니다.

6. 전체 분석 예제

  1. 유전체 FASTA 파일을 준비하거나 Get Data 패널에서 NCBI accession으로 다운로드합니다.
  2. 프로젝트 폴더를 작업 폴더로 선택합니다.
  3. Download DBs를 눌러 필요한 데이터베이스를 다운로드합니다.
  4. 필요한 경우 각 모듈의 매개변수를 설정합니다.
  5. Batch 모드에서 모듈을 선택하고 워크플로를 실행합니다.
  6. 파일 브라우저와 Preview 패널에서 결과를 확인합니다.

일반적인 워크플로는 Genome Stats, Prokka, CheckM, BUSCO, dbCAN, antiSMASH, PhyloPhlAn, AAI/ANI를 포함할 수 있습니다.

7. 재현성 보고서

  • TaxaScope_Run_Manifest.json: 기계 판독 가능한 실행 기록.
  • TaxaScope_Run_Report.md: 사람이 읽을 수 있는 Markdown 실행 보고서.
  • TaxaScope_Report.html: 결과와 provenance를 포함하는 대화형 HTML 보고서.

8. 문제 해결

컨테이너 런타임을 사용할 수 없으면 Podman 또는 Docker Desktop을 설치하거나 시작하십시오. 데이터베이스가 없으면 Download DBs를 실행하고 TaxaScope_Databases/database_sources.json 파일을 확인하십시오. 메모리 부족으로 실패하면 Low Perf Mode를 켜거나 컨테이너 런타임 메모리를 늘리십시오.
