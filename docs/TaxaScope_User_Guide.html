1. Overview

TaxaScope is an integrated GUI toolkit for microbial genome analysis on Windows. It provides a guided environment for configuring, executing, inspecting, and documenting genome-based taxonomic workflows.

  • Genome assembly statistics and annotation
  • Genome quality and completeness assessment
  • CAZyme and biosynthetic gene cluster analysis
  • ANI/AAI comparison and whole-genome phylogeny
  • HTML, Markdown, and JSON reproducibility reporting

2. Graphical User Interface and Workflow Configuration

Figure 2. Graphical user interface (GUI) of TaxaScope and workflow configuration.

  1. Environment setup: click Env Setup for first-time WSL2 and container engine initialization. This is required only once.
  2. Working directory selection: click Select Work Directory and choose the project folder containing inputs and outputs.
  3. Database download: click Download DBs to install required reference databases into the selected working directory.
  4. Parameter configuration: use the module tabs, such as Prokka, CheckM, BUSCO, dbCAN, antiSMASH, PhyloPhlAn, and AAI/ANI, to adjust tool-specific settings.
  5. Data acquisition: use Get Data to paste GCA/GCF accessions and download genomes, or place local FASTA/FA/FNA/FAA files in the working directory.
  6. Workflow selection: open Batch mode and select the modules to run sequentially.
  7. Workflow execution: click Deploy Complete Workflow to start the selected pipeline.

The left panel displays the file browser. The central panel presents workflow configuration and module selection. The right panel contains Runtime, Console, and Preview tabs for progress monitoring, logs, troubleshooting, and result visualization.

3. System Requirements

  • Windows 10 or Windows 11
  • WSL2
  • Podman or Docker Desktop configured for Linux containers
  • At least 16 GB RAM for small bacterial genome batches
  • 32 GB RAM or higher for CheckM2, antiSMASH, and larger batch workflows
TaxaScope primarily uses Podman on Windows, while the main analysis modules include Docker fallback support when Docker Desktop is installed and running.

5. Database Setup

Reference databases are stored under the selected working directory:

<working directory>/TaxaScope_Databases

The database folder includes database_sources.json, which records database names, versions, download sources, and notes for reproducibility reporting.

6. Complete Analysis Case

  1. Open TaxaScope.exe. If this is the first run, click Env Setup. Windows 10 users should use the WSL2 setup helper when prompted, then reboot before analysis.
  2. Confirm the environment status. When the interface shows Env Ready, the container runtime is available. Use VM Config only when the Podman VM needs memory/CPU adjustment or repair.
  3. Click Select Work Directory and choose a project folder. TaxaScope uses this folder for input files, intermediate files, tool outputs, databases, and reports.
  4. Click Download DBs to install reference databases. This creates TaxaScope_Databases and records database source information in database_sources.json.
  5. Add input data. Either paste GCA/GCF accessions in Get Data and download assemblies from NCBI, or place local genome/protein sequence files directly in the working directory.
  6. Open individual module tabs to review parameters. For example, select dbCAN methods, adjust antiSMASH strictness, or enable Low Perf Mode for memory-limited machines.
  7. Open Batch mode, select the modules to run, and keep report generation enabled when a summary report is needed.
  8. Click Deploy Complete Workflow. The Runtime tab shows progress, and the Console tab records the exact command-line logs.
  9. After completion, select output files from the left file browser. Tables, figures, reports, and tree files can be inspected in the Preview tab.
  10. Review the generated reports: TaxaScope_Report.html, TaxaScope_Run_Report.md, and TaxaScope_Run_Manifest.json.

A typical workflow can include Genome Stats, Prokka, CheckM, BUSCO, dbCAN, antiSMASH, PhyloPhlAn, and AAI/ANI.

7. Reproducibility Reports

  • TaxaScope_Run_Manifest.json: machine-readable run manifest.
  • TaxaScope_Run_Report.md: human-readable Markdown run report.
  • TaxaScope_Report.html: interactive HTML report with results and provenance.

8. Troubleshooting

If the container runtime is unavailable, install or start Podman or Docker Desktop. If databases are missing, run Download DBs and confirm that TaxaScope_Databases/database_sources.json exists. If a module fails because of memory, enable Low Perf Mode or increase container runtime memory allocation.

1. 软件概述

TaxaScope 是一个面向 Windows 的微生物基因组分析 GUI 工具。它将容器化执行、工作目录管理、数据库追踪、批量流程配置、结果预览和结构化运行报告整合到一个桌面界面中。

  • 基因组统计和注释
  • 基因组质量和完整性评估
  • CAZyme 和次级代谢基因簇分析
  • ANI/AAI 比较和全基因组系统发育分析
  • HTML、Markdown 和 JSON 复现性报告

2. 图形界面和工作流配置

图 2. TaxaScope 图形用户界面和工作流配置。

  1. 环境初始化：首次使用时点击 Env Setup，初始化 WSL2 和容器引擎。这个步骤只需要做一次。
  2. 选择工作目录：点击 Select Work Directory，选择项目文件夹。输入、中间文件和输出都会保存在这里。
  3. 下载数据库：点击 Download DBs，把所需参考数据库安装到当前工作目录。
  4. 配置参数：通过 Prokka、CheckM、BUSCO、dbCAN、antiSMASH、PhyloPhlAn、AAI/ANI 等模块标签页调整工具参数。
  5. 获取数据：在 Get Data 中粘贴 GCA/GCF accession 从 NCBI 下载基因组，也可以直接把本地 FASTA/FA/FNA/FAA 文件放进工作目录。
  6. 选择批量流程：进入 Batch 模式，勾选需要按顺序运行的模块。
  7. 执行工作流：点击 Deploy Complete Workflow 启动所选流程。

左侧面板是文件浏览器，显示工作目录中的输入、中间文件和输出。中间面板用于配置流程和选择分析模块。右侧面板包含 Runtime、Console 和 Preview 三个标签，用于查看进度、日志、故障排查和结果预览。

3. 系统要求

  • Windows 10 或 Windows 11
  • WSL2
  • Podman 或配置为 Linux containers 的 Docker Desktop
  • 小规模细菌基因组分析建议至少 16 GB 内存
  • CheckM2、antiSMASH 和较大批量流程建议 32 GB 或更高内存
TaxaScope 在 Windows 上默认优先使用 Podman；主要分析模块在 Docker Desktop 已安装并运行时也支持 Docker fallback。

5. 数据库设置

参考数据库存放在所选工作目录下：

<working directory>/TaxaScope_Databases

其中 database_sources.json 用于记录数据库名称、版本、下载来源和备注，并写入复现性报告。

6. 完整分析案例

  1. 打开 TaxaScope.exe。如果是第一次使用，先点击 Env Setup。Windows 10 用户按提示完成 WSL2 设置后需要重启电脑。
  2. 确认环境状态。界面显示 Env Ready 后说明容器运行环境可用。只有需要调整 Podman VM 内存、CPU 或修复环境时才点击 VM Config。
  3. 点击 Select Work Directory，选择项目文件夹。TaxaScope 会把输入文件、中间文件、输出、数据库和报告都放在这个目录下。
  4. 点击 Download DBs 下载参考数据库。程序会创建 TaxaScope_Databases，并在 database_sources.json 中记录数据库来源和版本。
  5. 添加输入数据。可以在 Get Data 中粘贴 GCA/GCF accession 从 NCBI 下载，也可以直接把本地基因组或蛋白序列文件放入工作目录。
  6. 进入单个模块标签页检查参数。例如选择 dbCAN 方法、设置 antiSMASH strictness，或在内存较低的机器上开启 Low Perf Mode。
  7. 进入 Batch 模式，勾选需要运行的模块；如果需要汇总报告，保持报告生成选项开启。
  8. 点击 Deploy Complete Workflow 开始运行。Runtime 标签显示进度，Console 标签记录命令行日志。
  9. 运行结束后，在左侧文件浏览器选择输出文件。表格、图片、报告和树文件可在 Preview 标签中查看。
  10. 检查生成的报告：TaxaScope_Report.html、TaxaScope_Run_Report.md 和 TaxaScope_Run_Manifest.json。

常见流程包括 Genome Stats、Prokka、CheckM、BUSCO、dbCAN、antiSMASH、PhyloPhlAn 和 AAI/ANI。

7. 复现性报告

  • TaxaScope_Run_Manifest.json：机器可读的运行记录。
  • TaxaScope_Run_Report.md：人工可读的 Markdown 运行报告。
  • TaxaScope_Report.html：包含结果和 provenance 的交互式 HTML 报告。

8. 故障排查

如果容器运行时不可用，请启动或安装 Podman/Docker Desktop。如果数据库缺失，请运行 Download DBs 并确认 TaxaScope_Databases/database_sources.json 存在。如果模块因内存不足失败，请启用 Low Perf Mode 或提高容器运行时内存。

1. 개요

TaxaScope는 Windows 환경에서 미생물 유전체 분석을 수행하기 위한 GUI 도구입니다. 컨테이너 실행, 작업 폴더 관리, 데이터베이스 추적, 배치 워크플로 설정, 결과 미리보기, 구조화된 실행 보고서를 하나의 인터페이스로 제공합니다.

  • 유전체 통계 및 주석
  • 유전체 품질 및 완전성 평가
  • CAZyme 및 생합성 유전자 클러스터 분석
  • ANI/AAI 비교 및 전장 유전체 계통분석
  • HTML, Markdown, JSON 재현성 보고서

2. GUI 및 워크플로 설정

그림 2. TaxaScope GUI 및 워크플로 설정.

  1. 환경 설정: 처음 사용할 때 Env Setup을 클릭하여 WSL2와 컨테이너 엔진을 초기화합니다. 이 단계는 한 번만 필요합니다.
  2. 작업 폴더 선택: Select Work Directory를 클릭하고 입력, 중간 파일, 출력이 저장될 프로젝트 폴더를 선택합니다.
  3. 데이터베이스 다운로드: Download DBs를 클릭하여 필요한 참조 데이터베이스를 작업 폴더에 설치합니다.
  4. 매개변수 설정: Prokka, CheckM, BUSCO, dbCAN, antiSMASH, PhyloPhlAn, AAI/ANI 탭에서 도구별 설정을 조정합니다.
  5. 데이터 수집: Get Data에서 GCA/GCF accession을 붙여 넣어 NCBI에서 유전체를 다운로드하거나, 로컬 FASTA/FA/FNA/FAA 파일을 작업 폴더에 넣습니다.
  6. 배치 워크플로 선택: Batch 모드에서 순차적으로 실행할 모듈을 선택합니다.
  7. 워크플로 실행: Deploy Complete Workflow를 클릭하여 선택한 파이프라인을 시작합니다.

왼쪽 패널은 파일 브라우저입니다. 가운데 패널은 워크플로 및 모듈 설정을 표시합니다. 오른쪽 패널은 Runtime, Console, Preview 탭을 통해 진행 상황, 로그, 문제 해결, 결과 미리보기를 제공합니다.

3. 시스템 요구사항

  • Windows 10 또는 Windows 11
  • WSL2
  • Linux containers로 설정된 Podman 또는 Docker Desktop
  • 소규모 세균 유전체 배치에는 최소 16 GB RAM 권장
  • CheckM2, antiSMASH 및 대규모 배치에는 32 GB 이상 권장
TaxaScope는 Windows에서 Podman을 우선 사용하지만, 주요 분석 모듈은 Docker Desktop이 실행 중인 경우 Docker fallback을 지원합니다.

5. 데이터베이스 설정

참조 데이터베이스는 선택한 작업 폴더 아래에 저장됩니다.

<working directory>/TaxaScope_Databases

database_sources.json 파일은 데이터베이스 이름, 버전, 다운로드 출처, 메모를 기록하며 재현성 보고서에 사용됩니다.

6. 전체 분석 예제

  1. TaxaScope.exe를 실행합니다. 처음 사용하는 경우 Env Setup을 클릭합니다. Windows 10 사용자는 WSL2 설정 후 재부팅해야 합니다.
  2. 환경 상태를 확인합니다. 인터페이스에 Env Ready가 표시되면 컨테이너 런타임을 사용할 수 있습니다. Podman VM의 메모리/CPU 조정이나 복구가 필요할 때만 VM Config를 사용합니다.
  3. Select Work Directory를 클릭하여 프로젝트 폴더를 선택합니다. 입력, 중간 파일, 출력, 데이터베이스, 보고서가 이 폴더에 저장됩니다.
  4. Download DBs를 클릭하여 참조 데이터베이스를 설치합니다. TaxaScope_Databases 폴더와 database_sources.json 기록 파일이 생성됩니다.
  5. 입력 데이터를 추가합니다. Get Data에 GCA/GCF accession을 입력하여 NCBI에서 다운로드하거나, 로컬 유전체/단백질 서열 파일을 작업 폴더에 넣습니다.
  6. 각 모듈 탭에서 매개변수를 확인합니다. 예를 들어 dbCAN 방법 선택, antiSMASH strictness 설정, 메모리가 부족한 장비에서 Low Perf Mode 사용 등이 가능합니다.
  7. Batch 모드에서 실행할 모듈을 선택하고, 요약 보고서가 필요한 경우 보고서 생성 옵션을 유지합니다.
  8. Deploy Complete Workflow를 클릭합니다. Runtime 탭은 진행 상황을 표시하고 Console 탭은 명령줄 로그를 기록합니다.
  9. 완료 후 왼쪽 파일 브라우저에서 출력 파일을 선택합니다. 표, 그림, 보고서, 트리 파일은 Preview 탭에서 확인할 수 있습니다.
  10. 생성된 보고서 TaxaScope_Report.html, TaxaScope_Run_Report.md, TaxaScope_Run_Manifest.json을 확인합니다.

일반적인 워크플로는 Genome Stats, Prokka, CheckM, BUSCO, dbCAN, antiSMASH, PhyloPhlAn, AAI/ANI를 포함할 수 있습니다.

7. 재현성 보고서

  • TaxaScope_Run_Manifest.json: 기계 판독 가능한 실행 기록.
  • TaxaScope_Run_Report.md: 사람이 읽을 수 있는 Markdown 실행 보고서.
  • TaxaScope_Report.html: 결과와 provenance를 포함하는 대화형 HTML 보고서.

8. 문제 해결

컨테이너 런타임을 사용할 수 없으면 Podman 또는 Docker Desktop을 설치하거나 시작하십시오. 데이터베이스가 없으면 Download DBs를 실행하고 TaxaScope_Databases/database_sources.json 파일을 확인하십시오. 메모리 부족으로 실패하면 Low Perf Mode를 켜거나 컨테이너 런타임 메모리를 늘리십시오.
